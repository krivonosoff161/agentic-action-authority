## Scope

- Adds public `DocumentHost` for preparing and reopening one create-only UTF-8
  document task, exposing exact review files, applying a separately signed
  operator decision, binding a content-only callback and recovering without
  delivery. The optional adapter reuses the Harness 1.14.2 guarded writer.
- Requires independent expected public-key fingerprint enrollment and the
  host-declared `owner/repository` plus exact revision. Neither a received key
  file nor a syntactically valid SHA proves operator or remote Git identity.
- Keeps the core import independent of Harness, model and network use. No new
  effect backend, arbitrary-agent sandbox or content-truth guarantee is added.

## Compatibility and evidence

The host `setup` CLI adds required `--expected-key-fingerprint` and
`--host-repository` arguments; `DocumentHost.prepare` requires corresponding
Python inputs. Existing 0.1.1 task state is not automatically migrated or
overwritten. See [upgrade notes](../upgrading-0.2.md) before using the new path.

The version's expected installed checks are core **29** and Harness **93**
per supported Windows/Linux lane, with zero skipped tests accepted. Those are
