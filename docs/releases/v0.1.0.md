# 0.1.0 — separate exact-action approval component

Release preparation. Consult the GitHub release and package index for publication;
this source document alone is not an upload receipt.

The distribution owns ActionCore, ActionGate, operator signing and the host CLI.
Core-only installation needs cryptography, not Harness. The optional file adapter
uses the existing Harness 1.14.2 create-only writer; it does not copy that writer.
There is no model, network or provider credential in the approval path.

The supported first effect is one exact UTF-8 file. Signed decisions bind payload,
destination, policy, declared dependencies and expiry. One attempt is durably
coordinated; uncertain recovery does not replay the effect. Generic EffectPort is
a trusted-host extension contract, not proof of arbitrary tool safety.
