## Scope

- Adds public, trusted-host-only `DocumentHost.execute_approved()`. After a
  separate signed decision is applied, it restores the exact retained document
  and calls the same approval gate and Harness create-only writer used by the
  host CLI. It takes no caller content, destination or approval arguments and
  is not an agent tool.
- Keeps the 0.2.0 `DocumentHost.bind_tool()` content callback, its strict
  descriptor and argument checks, and the existing file-v1 and generic-v2
  signature domains. No task-state migration or new effect backend is added.
- Improves the operator CLI's presentation of decision, action, destination,
  byte count and deadline. The full escaped request and exact document still
  precede typed confirmation and local passphrase entry. This is presentation,
  not a different approval protocol or a transport authentication claim.
- Retains the optional Harness 1.14.2 writer, one spent attempt at durable
  BEGIN, pre-BEGIN revocation ordering, and recovery by readback/fencing
  without delivery. An uncertain outcome does not authorize replay.

## Compatibility and verification boundaries

The 0.2.0 wheel has `DocumentHost` and the content callback but does not have
`execute_approved()`. Existing 0.2.0 integration can keep using that callback;
hosts adopting the new method need a verified 0.3.0 installation. Version 0.1.1
lacks `DocumentHost` and its onboarding requirements; see the historical
[upgrade notes](../upgrading-0.2.md). Neither an install nor this version change
enrolls an operator or approves a task.

The expected installed test inventory is core **33** and optional Harness
**112** per supported Windows/Linux lane, with zero skipped tests accepted.
These counts are bookkeeping, not completed CI or publication results and not
a security score. The finite route measurement compares two correct paths in
the same installed build: exact retained-byte content callback and host-only
execution. It measures local API friction and timing, with no speedup threshold
or required saved model call. Synthetic signatures and tests are not human
consent, independent review or an external user pilot.

The test-only ordinary local approval reference uses the same Harness operation
with frozen content/destination and a durable SQLite spent admission. It assumes
an authenticated local operator callback; its injected failure/readback checks
are same-process checks, not proof of process-restart parity or vendor behavior.
No measured competitive superiority, human integration time or adoption claim
follows from this release scope.
